	\item Qual era o problema investigado?
	\item Qual era o objetivo geral?
	\item O objetivo geral foi alcançado?
	\item Quais objetivos específicos foram alcançados?
	\item Quais foram as principais descobertas?
	\item Qual é a principal contribuição científica ou tecnológica?
	\item Quais resultados mais relevantes sustentam a conclusão?
	\item Quais limitações permaneceram?
	\item Quais questões permaneceram sem resposta?
