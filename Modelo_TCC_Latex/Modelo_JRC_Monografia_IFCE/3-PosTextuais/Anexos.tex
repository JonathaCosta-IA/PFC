\chapter{Anexos}
% =========================================================

O anexo deve conter material produzido por terceiros ou documentação externa
que seja necessária ou relevante para complementar o trabalho.

\begin{enumerate}
	\item Existe documentação externa necessária para compreender o trabalho?
	\item O material foi produzido por outro autor ou instituição?
	\item Há normas técnicas relevantes?
	\item Há \textit{datasheets}?
	\item Há manuais?
	\item Há especificações de fabricantes?
	\item Há documentos oficiais?
	\item Há legislação ou regulamentação pertinente?
	\item Há instrumentos ou documentos externos utilizados na pesquisa?
	\item O documento realmente precisa estar anexado ou uma referência seria suficiente?
\end{enumerate}
